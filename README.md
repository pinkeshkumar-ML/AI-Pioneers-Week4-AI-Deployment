# Week 4 — AI Project Deployment & Capstone

## Project
**Student Score Predictor** — an educational end-to-end machine-learning application. It trains a regression model on synthetic data and serves predictions through a Flask API and a small web page.

> The dataset is synthetic. Predictions are for demonstration only and must not be treated as real academic results.

## Features
- Reproducible synthetic dataset generation
- Train/test split and feature scaling in a scikit-learn pipeline
- Linear Regression model training
- MAE, RMSE, and R² evaluation
- Model serialization with Joblib
- Flask web interface and JSON prediction endpoint
- Input validation and health-check endpoint

## Files
- `train_model.py` — creates data, trains/evaluates the model, and saves artifacts
- `app.py` — Flask application (`/`, `/predict`, `/health`)
- `requirements.txt` — Python dependencies
- `student_scores_sample.csv` — generated by the training script
- `evaluation_metrics.csv` — generated by the training script
- `model.joblib` — generated trained model; create it locally by running the training script

## Run locally
Use Python 3.10 or newer.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install and train:
```bash
pip install -r requirements.txt
python train_model.py
```

Start the app:
```bash
python app.py
```

Open `http://127.0.0.1:5000` in a browser.

## API
`POST /predict`

Example JSON:
```json
{
  "study_hours": 4,
  "attendance": 80,
  "previous_score": 65
}
```

Example response:
```json
{
  "predicted_score": 75.12
}
```
The numeric output depends on the generated model; do not rely on this illustrative value.

Health check: `GET /health`

## Deployment
For a hosted deployment, push the project to GitHub and use a Python-compatible hosting platform that supports Flask. Set the start command to `gunicorn app:app` if the platform supports Gunicorn, and add `gunicorn` to `requirements.txt`. Run `python train_model.py` during the build/release process or commit the generated `model.joblib` only if your course instructions allow it. Never load untrusted Joblib/Pickle files.

## Limitations and future work
- Uses synthetic, simplified data rather than real student records.
- Linear Regression is a baseline model.
- Future improvements include real validated data, more models, automated tests, monitoring, and a hosted URL.
